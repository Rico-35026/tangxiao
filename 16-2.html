🧱 JavaScript 对象与字符串

📦 当前对象（名为 user）

① 对象：创建 / 访问 / 增删改

对象字面量

用 { } 直接写键值对，值可以是任意类型。
const user = { name: "唐笑", age: 19, city: "北京" };

访问属性

点语法 user.name 或方括号 user["age"]。
user.name // "唐笑" user["age"] // 19

增 / 改 / 删

直接赋值增改，delete 删除属性。
user.age = 20; // 改 user.email = "a@x.com"; // 增 delete user.city; // 删

对象方法

属性值可以是函数，调用 this 指代对象本身。
const u = { name: "唐笑", say() { return "我是"+this.name; } }; u.say();

遍历 for...in

逐个取出对象的键名 key。
for (let k in user) { console.log(k, user[k]); }

keys / values / entries

把对象转成数组：键、值、键值对。
Object.keys(user) Object.values(user) Object.entries(user)

解构赋值

一次性把属性取成独立变量。
const { name, age } = user; // name、age 成为变量

展开运算符 {...}

快速复制并合并对象（后者覆盖前者）。
const copy = { ...user }; const ext = { ...user, vip: true };

嵌套对象

属性值本身又是一个对象，用链式访问。
user.addr.city // 北京 user.addr.zip // 100000

length = 0
② 字符串：常用方法

length / charAt

length 是长度（字符数），charAt(i) 取第 i 个字符。
str.length // 字符数 str.charAt(2) // 第2个

toUpperCase / toLowerCase

转为大写 / 小写（不影响原串）。
str.toUpperCase() str.toLowerCase()

trim()

去掉首尾空白字符。
str.trim() // 去头尾空格

indexOf / includes

查位置 / 判断是否包含子串。
str.indexOf("JS") // 下标 str.includes("JS") // true/false

slice / substring

截取子串，[起, 止)。
str.slice(2, 7) // 第2~6个 str.substring(2,7)

split()

按分隔符把字符串拆成数组。
str.trim().split(" ") // 按空格拆

replace()

替换第一个匹配的子串。
str.replace("JS", "JavaScript")

repeat()

把字符串重复 n 次。
"!".repeat(3) // "!!!" "ab".repeat(2) // "abab"

padStart / padEnd

用填充符补齐到指定长度（前/后补）。
"7".padStart(3, "0") // "007" "7".padEnd(3, "0") // "700"

模板字符串

反引号内用 ${} 嵌入变量/表达式。
const n = "唐笑"; `你好，${n}！长度=${str.length}`
