什么是 CSS 变量

CSS 变量（自定义属性）允许你在样式表中定义可重复使用的值。使用 --变量名 定义，通过 var(--变量名) 引用。

/* 定义变量 */
:root {
    /* 以 -- 开头定义自定义属性 */
    --primary-color: #e94560;
    --spacing: 20px;
    --font-size: 16px;
}

/* 使用变量 */
.button {
    background: var(--primary-color);
    padding: var(--spacing);
    font-size: var(--font-size);
}

以下是使用 CSS 变量构建的卡片组件，所有颜色、间距、圆角均通过变量控制。

颜色变量

变量作用域

CSS 变量遵循层叠规则：全局变量定义在 :root，局部变量可在任意选择器中覆盖。

全局变量 (:root)

定义在整个文档根元素，所有元素都可访问。

:root { --local-color: #e94560; }
全局变量

局部变量

定义在特定选择器内，仅该选择器及其子元素可访问。

.local { --local-color: #4ecca3; }
局部变量

变量覆盖

子元素中同名变量会覆盖父级定义。

.override { --local-color: #f39c12; }
覆盖变量

JavaScript 操作变量

通过 JS 动态修改变量值，实现运行时主题切换。

// 获取 :root 元素
const root = document.querySelector(':root');

// 修改变量值
root.style.setProperty('--primary-color', '#4ecca3');

// 获取变量值
const color = root.style.getPropertyValue('--primary-color');

使用建议

命名规范

使用 -- 前缀，采用小写短横线命名，如 --primary-color。

回退值

使用 var(--color, #333) 提供默认值，兼容旧浏览器。

统一管理

在 :root 集中定义设计系统的颜色、间距、字体等。

动态交互

结合 JS 实现主题切换、用户偏好设置等动态功能。
