① JSON 是什么 JavaScript Object Notation
JSON 是一种轻量级数据交换格式，本质是 JavaScript 对象的字符串表示。 只能包含：对象 {}、数组 []、字符串 ""、数字、布尔 true/false、null。 不能包含：函数、undefined、变量、注释。
② 原始 JSON 字符串 后端返回的就是这种
③ JSON.parse(jsonStr) 字符串 → JS 对象
// 把 JSON 字符串解析成可操作的 JS 对象 let tx_obj = JSON.parse(tx_jsonStr); console.log(tx_obj.user.name); // "唐笑" console.log(tx_obj.hobbies[0]); // "HTML"
