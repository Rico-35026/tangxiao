🧩 JavaScript 主要数组方法

作者：唐笑 · 把数组画成方块，点一点看方法如何改变它

📦 当前数组（名为 arr）

① 增 / 删 / 改（改变原数组）

push()

在末尾追加元素，返回新长度。
arr.push(8) // 追加数字 8

pop()

删除并返回最后一个元素。
arr.pop() // 删除末尾

unshift()

在开头插入元素，返回新长度。
arr.unshift(0) // 开头插入 0

shift()

删除并返回第一个元素。
arr.shift() // 删除开头

splice()

从指定位置删除/插入，可同时改数组。
arr.splice(1, 2, 99) // 第1位起删2个，插入99

reverse()

原地倒序排列数组。
arr.reverse()

sort()

原地排序（默认按字符串，建议传比较函数）。
arr.sort((a,b)=>a-b) // 数值升序
② 遍历 / 生成新数组（不改动原数组）

forEach()

遍历每个元素，无返回值（仅执行操作）。
arr.forEach(v => ...) // 依次处理每个值

map()

对每个元素加工，返回一个新数组。
arr.map(v => v * 2) // 每个数翻倍

filter()

按条件筛选，返回满足条件的新数组。
arr.filter(v => v > 4) // 只留大于4

reduce()

累加/汇总，最终返回单个结果。
arr.reduce((s,v)=>s+v, 0) // 求和
③ 查找 / 判断

find()

返回第一个满足条件的元素。
arr.find(v => v > 5) // 第一个>5的

findIndex()

返回第一个满足条件的元素下标，没有则 -1。
arr.findIndex(v => v > 5)

includes()

判断数组是否包含某值，返回 true/false。
arr.includes(7) // 是否含 7

indexOf()

返回某值首次出现的下标，没有则 -1。
arr.indexOf(9)

some() / every()

some：有一个满足即 true；every：全部满足才 true。
arr.some(v=>v>8) arr.every(v=>v>0)
④ 返回新数组 / 字符串

slice()

截取一段（[起, 止)），不改变原数组。
arr.slice(1, 3) // 取第1~2位

concat()

拼接数组，返回新数组（原数组不变）。
arr.concat([10, 20])

join()

用指定连接符把数组拼成字符串。
arr.join('-') // 用 - 连接
