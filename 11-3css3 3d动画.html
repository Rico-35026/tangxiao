3D 变换属性

属性 说明 示例
perspective 定义3D元素的透视效果 perspective: 800px;
transform-style 指定子元素是否在3D空间中呈现 transform-style: preserve-3d;
rotateX() 绕X轴旋转 transform: rotateX(45deg);
rotateY() 绕Y轴旋转 transform: rotateY(45deg);
rotateZ() 绕Z轴旋转 transform: rotateZ(45deg);
translateZ() 沿Z轴平移 transform: translateZ(50px);
scaleZ() 沿Z轴缩放 transform: scaleZ(1.5);
backface-visibility 控制元素背面是否可见 backface-visibility: hidden;

关键帧动画

使用 @keyframes 创建复杂的3D动画序列。

持续旋转

立方体绕X和Y轴持续旋转。

@keyframes rotate-cube {
  0% { transform: rotateX(0) rotateY(0); }
  100% { transform: rotateX(360deg) rotateY(360deg); }
}

翻转效果

卡片悬停时180度翻转。

.flip-card:hover .flip-inner {
  transform: rotateY(180deg);
}

轮播旋转

多个面片绕中心旋转。

@keyframes carousel-spin {
  0% { transform: rotateY(0); }
  100% { transform: rotateY(360deg); }
}
